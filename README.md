# Sales-Performance-Dashboard
This project focuses on analyzing sales data and presenting key business insights through an interactive dashboard created in Microsoft Excel. The dashboard enables efficient monitoring of sales performance, KPIs, and business trends using advanced Excel functionalities.
Key Features
Interactive dashboard with charts, Pivot Tables, and slicers.
KPI monitoring for sales performance and target achievement.
Automated reporting using Excel formulas and data analysis techniques.
Data cleaning and preprocessing to ensure accuracy and consistency.
Trend analysis and performance tracking across different sales categories.
Tools & Technologies
Microsoft Excel
Pivot Tables
Pivot Charts
Advanced Formulas
Data Validation & Conditional Formatting
